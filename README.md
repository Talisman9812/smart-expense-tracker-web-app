# Smart Expense Tracker Web App

A mobile-friendly expense tracker built with HTML, CSS, and JavaScript.

## Features

- Add, edit, and delete expenses
- Monthly budget tracking
- Remaining balance display
- Budget progress bar
- Category filtering
- Search by name, category, or date
- Spending chart by category
- Local browser storage
- CSV export for Excel or Google Sheets
- Responsive mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- CSV export
